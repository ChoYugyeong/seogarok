개인정보처리방침

시행일: 2026-10-30 · 버전 1.0 · 서가록(SEOGAROK, https://seogarok.com)

서가록은 이용자의 개인정보를 최소한으로 수집하며, 로그인 없이도 모든 기능(검색·가용성 확인·내 서재·알림)을 사용할 수 있습니다. 구글 로그인은 선택이며, 기기 간 서재 동기화를 원할 때만 사용됩니다. 본 방침은 「개인정보 보호법」 등 관련 법령을 준수합니다.

1. 처리 목적

목적내용
서비스 제공도서 검색, 구독 가용성·종료 예정 정보 제공, 내 서재(관심/읽는 중/완독), 종료 알림
기기 간 동기화(선택)구글 로그인 이용자가 여러 기기에서 같은 서재를 사용할 수 있도록 저장
서비스 개선개인을 식별하지 않는 익명 통계(검색 성공률, 클릭 흐름 등)
장애 대응서버 접속 로그(IP 미기록) — 오류 분석 목적

2. 처리하는 개인정보 항목

구분항목수집 시점

내 서재 동기화(로그인 시)관심/읽는 중/완독 책 ID 목록서재 변경 시

접속 로그요청 시각·경로·응답코드·처리시간·사용자 에이전트 (IP 원본 미기록)요청 시

주민등록번호, 비밀번호, 결제정보, 위치정보, 연락처는 수집하지 않습니다. 광고·추적 쿠키를 사용하지 않습니다.

3. 보관 기간 및 파기

데이터보관 기간파기 방법
구글 로그인 계정 정보회원 탈퇴 시까지탈퇴 즉시 GCS 객체 삭제
동기화된 내 서재회원 탈퇴 시까지탈퇴 즉시 삭제
세션 쿠키최대 30일로그아웃·만료 시 삭제

개인정보 문의 기록처리 완료 후 1년기간 경과 후 파기
익명 통계최대 90일자동 파기
접속 로그최대 30일클라우드 로그 정책에 따라 자동 파기

이용자는 로그인 후 내 서재 → 계정 삭제로 언제든 계정과 동기화 데이터를 즉시 삭제할 수 있습니다. 로그아웃만 해도 서버 동기화는 중지되며, 브라우저의 서재 데이터는 이용자 기기에 남습니다.

4. 제3자 제공 · 처리위탁

수탁/제3자목적항목
Google LLC (OAuth 로그인)구글 계정 인증로그인 시 인증 정보(이메일 등)
Google Cloud (Cloud Run·Cloud Storage)서비스 호스팅·데이터 저장(서울 리전 ASIA-NORTHEAST3)서비스 데이터

법령에 따른 요청이 있는 경우를 제외하고 개인정보를 제3자에게 판매·제공하지 않습니다.

5. 국외 이전

구글 로그인을 사용하는 경우 인증 처리를 위해 Google LLC(미국)로 인증 정보가 이전될 수 있습니다(목적: OAuth 인증, 보유: Google 정책에 따름). 서비스 데이터(서재 등)는 대한민국 서울 리전 Google Cloud Storage에 저장됩니다.

6. 정보주체의 권리

  • 개인정보 열람·정정·삭제·처리정지를 언제든 요청할 수 있습니다.
  • 로그인 후 계정 삭제 버튼으로 즉시 삭제할 수 있습니다.
  • 브라우저 저장소(localStorage·쿠키)는 브라우저 설정에서 직접 삭제할 수 있습니다.
  • 문의: 아래 10. 문의 참고.

7. 쿠키 및 세션

로그인 시 필수 세션 쿠키(__Host-seogarok_session, HttpOnly·Secure·SameSite=Lax, 최대 30일)를 사용합니다. 로그인하지 않으면 세션 쿠키를 설정하지 않습니다.

광고(선택): 이용자가 광고 쿠키에 동의한 경우에만 Google AdSense 광고가 표시되며, Google 및 제3자 광고 사업자가 쿠키를 사용해 맞춤형 광고를 제공할 수 있습니다. 동의하지 않으면 광고 스크립트·쿠키를 로드하지 않으며 모든 기능을 그대로 사용할 수 있습니다. Google 광고 설정에서 맞춤형 광고를 끌 수 있습니다: adssettings.google.com · 자세히: Google 광고 정책

8. 익명 통계

서비스 개선을 위해 개인을 식별하지 않는 통계(이벤트명, 검색어, 페이지 경로 등)를 수집합니다. 세션 ID는 랜덤 값이며 IP는 비식별 해시로만 처리합니다. 브라우저의 DNT(Do Not Track) 설정 시 수집하지 않으며, 최대 90일 후 파기합니다.

9. 안전성 확보 조치

  • 전송 구간 암호화: HTTPS(HSTS) 적용, HTTP → HTTPS 리다이렉트
  • 세션 보호: 세션 토큰은 서버에 해시로만 저장, 쿠키는 HttpOnly·Secure·SameSite=Lax
  • 접근 통제: 개인정보 저장소(GCS)는 비공개, 최소 권한 서비스계정만 접근
  • CSRF·남용 방지: 상태 변경 요청 출처 검증, 로그인 요청 rate limit, 요청 본문 크기 제한
  • OAuth 보안: state 값 서명·검증, 인증 코드 서버 측 교환, 제공자 토큰 미저장
  • 최소 수집: 로그인은 선택, 비밀번호·결제정보 미수집
  • 2단계 인증: 구글 계정의 2단계 인증 정책을 그대로 따릅니다. 서가록은 비밀번호를 저장하지 않습니다.
  • 계정 삭제: 동기화 서재·세션·연결된 푸시 구독을 즉시 파기

10. 문의

개인정보 열람·정정·삭제·처리정지 요청은 개인정보 문의 양식으로 접수해 주세요(7일 이내 회신). 양식 이용이 어려우면 GitHub 이슈로도 접수할 수 있습니다. 처리 책임자: 서가록 운영자.
