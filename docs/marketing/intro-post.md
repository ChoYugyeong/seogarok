# 소개 글 초안 — 서가록 (SEOGAROK)

> 목적: 외부 백링크 + 브랜드 검색 유입. 아래 3개 버전 중 상황에 맞게 사용.
> 링크: https://seogarok.com

---

## 버전 A — 브런치/블로그 (롱폼, 800~1,200자)

### 제목 후보
1. **"이 책, 지금 어느 구독에 있나?" — 왓챠피디아의 책 버전을 만들어봤다**
2. 밀리·리디셀렉트·교보 sam·윌라, 책 한 권이 어디에 있는지 한 번에 확인하는 법
3. 구독 서비스 4곳을 오가며 책 찾던 사람이 만든 서비스 (feat. 서가록)

### 본문

책을 읽고 싶어서 여러 구독 서비스를 오가다 보면, 같은 책을 **밀리의 서재**에도, **리디셀렉트**에도, **교보 sam**에도, **윌라**에도 각각 검색해봐야 하는 게 은근히 번거롭습니다. "이 책이 지금 내 구독에 있는지"는 물론이고, "이번 달에 구독에서 내려가는 책"은 더더욱 한눈에 보이지 않습니다.

그래서 만들었습니다. **서가록 (seogarok.com)** — 책의 **가용성 레이어**입니다.

- **한 번 검색으로 4개 구독의 보유 여부**를 확인
- **종료 예정일**을 추적해 "곧 사라지는 책"을 미리 알림
- 왓챠피디아처럼 **취향 기반**으로 책을 둘러보되, 추천보다 **어디서 읽을 수 있는지**에 집중했습니다
- 예스24 Open API 기반 **베스트셀러·스테디셀러·신간** 흐름도 함께 확인

기술적으로는 한국어 도서 검색을 위해 **BM25 + 벡터 하이브리드 검색**, **초성 검색**, **ISBN 우선 매칭**을 넣었고, 4,000여 권 이상의 책 가용성 데이터를 매일 갱신합니다. 서버는 표준 라이브러리 + SQLite로 가볍게 돌아가고, GCP Cloud Run에서 운영 중입니다.

아직 부족한 부분도 있습니다. 모든 구독의 보유 여부가 100% 공개되는 건 아니라서, **확인된 정보와 추정 가능한 정보를 구분해서** 보여주고 있습니다. 데이터가 비어 있는 책은 "가용성 미확인"으로 표시합니다. (틀린 정보를 자신 있게 보여주는 것보다 낫다고 생각했습니다.)

지금은 무료로 열려 있고, 아래에서 바로 확인할 수 있습니다.

👉 https://seogarok.com

책을 구독으로 읽는 분들께 조금이라도 도움이 되면 좋겠습니다.

## 버전 B — 커뮤니티/디스콰이엇 (숏폼)

### 제목
**구독 4곳을 오가며 책 검색하던 게 너무 불편해서 만들었습니다**

### 본문

밀리·리디셀렉트·교보 sam·윌라에 같은 책이 있는지 각각 검색하는 게 너무 번거로워서, **한 번에 확인하는 서비스**를 만들었습니다.

- 책 한 권이 **어느 구독에 있는지** 한 화면에서 확인
- **종료 예정(곧 내려가는 책)** 알림
- 초성 검색, 하이브리드 검색, 베스트셀러/스테디 흐름
- 4,000+권 가용성 데이터 매일 갱신

왓챠피디아의 책 버전을 목표로 했고, "추천"보다 **"어디서 읽을 수 있나"**에 집중했습니다.

👉 https://seogarok.com
