# 상표 출원 가이드 — "서가록 / SEOGAROK"

> 이 문서가 답하는 질문
> 1. 지금 "서가록"을 상표로 출원해도 되는가? (선행 조사 결과)
> 2. 어느 류(類)에, 무엇을 지정해 출원하는가?
> 3. 절차·비용·기간은 얼마이고, 다음 행동은 무엇인가?

---

## 1. 선행 조사 결과 (2026-10-28 기준)

| 조사 | 결과 |
|---|---|
| KIPRIS 상표 검색 "서가록" | **0건** (상표·서비스표·단체표장·증명표장·국제등록 전체, 국내/해외 각 0) |
| KIPRIS "SEOGAROK" | **0건** |
| 대조군 "서가" | 9,356건 (검색 정상 동작 확인) |
| 일반 사용례(웹 검색) | "서가록"을 브랜드로 쓰는 서비스/앱 발견 안 됨 |
| 도메인 | `seogarok.com` **등록 완료(운영 중)**, `.co.kr`·`.kr` 미등록 |

**결론: 현재 선점 없음. 출원 가능성이 높지만, 아래 2가지 리스크는 별도 검토 필요.**
1. 최근 출원분은 공개 지연(수개월)으로 검색에 안 잡힐 수 있음 → **출원 직전 재확인**
2. "서가"(書架)와 결합한 표장이라 **'서가' 계열 선행상표와의 유사 판단** 여지가 있음(특히 41류 서비스표)

## 2. 출원할 류(類)와 지정상품

Nice 분류 기준, 이 서비스에 필요한 4개 류:

| 류 | 대상 | 지정상품 예시 |
|---|---|---|
| **제9류** | 소프트웨어·앱 | 다운로드 가능한 컴퓨터 소프트웨어, 다운로드 가능한 전자출판물, 모바일 애플리케이션 |
| **제16류** | 인쇄물·서적 | 서적, 정기간행물, 브로슈어, 인쇄물 |
| **제35류** | 광고·판매촉진 | 광고대행업, 상품판매대행업, 온라인 마켓플레이스 제공, 상품전시업 |
| **제41류** | 출판·교육·도서관 | 전자출판업, 도서관 서비스, 독서교육, 오락정보 제공, 온라인 출판 |

> 지정상품은 **특허청 고시 「상품 및 서비스업의 분류」**의 정확한 명칭을 사용해야 한다.
> 위 예시는 초안이며, 출원 시 고시 명칭으로 확정해야 한다(변리사 검수 권장).

## 3. 비용·기간 (개인 출원 기준, 대략)

| 항목 | 비용 |
|---|---|
| 출원료(전자출원) | 약 **46,000원 / 류** (1류), 추가 1류당 2,000원 수준* |
| 등록료(10년) | 약 **211,000원 / 류** (분할 납부 가능)* |
| 변리사 수수료(선택) | 류당 20~40만원 (유사검색 포함) |
| **4류 합계** | **직접 출원 약 100만원 이내 / 변리사 대행 약 150~250만원** |

\* 관납료는 고시에 따라 변동될 수 있으니 **특허로(patent.go.kr) 전자출원 화면에서 최종 금액 확인**.

**기간:** 출원 → 방식심사 → 실체심사(보통 2~6개월) → 등록결정 → 등록료 납부 → 등록완료

---

## 4. 절차

```
① 선행 유사상표 검색 (KIPRIS → "유사상표 검색", 유사군코드로 9/16/35/41 확인)
② 지정상품 확정 (고시 명칭)
③ 전자출원 (특허로 https://www.patent.go.kr) 또는 변리사 의뢰
④ 출원번호 부여 → 방식심사 통과
⑤ 실체심사 (거절이유통지 시 의견서/보정서 제출)
⑥ 등록결정 → 등록료 납부 → 상표등록증 발급
⑦ 등록 후 10년, 갱신 가능
```

**개인 출원 준비물:** 성명·주소·주민등록번호(외국인은 대체 서류), 도장(전자서명), 카드결제 수단

## 5. 권장 시점과 순서

| 시점 | 할 일 |
|---|---|
| **지금** | `.co.kr` 도메인 확보(연 1~2만원) — 상표보다 싸고 선점 리스크만 방어 |
| **서비스 공개 직전** | KIPRIS 재검색 → 출원(9·16·35·41류) |
| 공개 후 | 브랜드 사용 증거(스크린숏·매출·광고) 보관 — 심사 대응·권리 행사에 사용 |
| 등록 후 | "서가록®" 표시, 앱스토어/블로그에 등록번호 기재 |

> ⚠️ **상표는 '사용'이 아니라 '출원'이 기준.** 공개 후 출원하면 제3자의 선출원에 밀릴 수 있으니,
> 앱 출시·SNS 홍보 **전에** 출원하는 것이 원칙이다.
